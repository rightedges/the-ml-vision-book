# Foundations of ML Vision

A comprehensive guide to building and deploying modern ML vision models.

This repository contains the source code and content for "Foundations of ML Vision", a book designed to take you from the first pixel to industrial-scale deployment.

## 📖 About the Book

"Foundations of ML Vision" bridges the gap between high-level theory and practical, hands-on implementation. We focus on the "Digital Apprentice"—understanding how machine learning models perceive the world and how we can guide them effectively.

## 🚀 Key Features

- **End-to-End Prototypes**: From the "Gate Guardian" (home security) to the "Logistics Lighthouse" (industrial scale).
- **Tool-Agnostic Concepts**: While we use PyTorch and OpenCV, the core concepts apply across the ML ecosystem.
- **Edge Deployment focus**: Learn how to run models on low-power hardware like the ESP32 and optimized edge servers.

## 📂 Project Structure

- `chapters/`: The core book content in Markdown format.
- `assets/`: Images and illustrations used in the book.
- `_config.yml`: Jekyll configuration for the book's web version.

## 🛠️ Local Development

This book is built using [Jekyll](https://jekyllrb.com/) and the [Just the Docs](https://just-the-docs.github.io/just-the-docs/) theme.

1. Install Ruby and Bundler.
2. Run `bundle install`.
3. Run `bundle exec jekyll serve` to view the book locally at `http://localhost:4000`.
